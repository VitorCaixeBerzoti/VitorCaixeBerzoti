# 👋 Olá, eu sou o Vitor Caixe Berzoti

Desenvolvedor focado em **aplicações web, APIs REST e automação de processos**.

Gosto de aprender colocando a mão na massa e transformar o que estudo em projetos reais, trabalhando tanto no **back-end** quanto no **front-end**.

Atualmente venho utilizando principalmente **JavaScript, TypeScript, React, Node.js e PostgreSQL**.

---

## 🚀 Projetos em destaque

### 🎫 [HelpDesk](https://github.com/VitorCaixeBerzoti/HelpDesk)

Sistema web para gerenciamento de chamados e solicitações.

- 🔐 Autenticação com JWT
- 👥 Controle de acesso por usuário e administrador
- 🎫 Criação e gerenciamento de chamados
- ⚛️ Front-end com React
- 🟢 API REST com Node.js
- 🗄️ PostgreSQL + Prisma

---

### 📦 [Central de Pedidos](https://github.com/VitorCaixeBerzoti/central-pedidos)

API para gerenciamento e integração de pedidos de diferentes empresas.

- 🚀 API REST
- 🔐 Autenticação com JWT
- ✅ Validação de dados com Zod
- 🔎 Paginação e filtros
- 📦 Gerenciamento de pedidos e itens
- 🔄 Controle de status
- 🗄️ PostgreSQL + Prisma
- 🐳 Docker

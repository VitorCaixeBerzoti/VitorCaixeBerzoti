## 🚀 Projetos em destaque

### 🎫 HelpDesk

Sistema completo para gerenciamento de chamados internos.

**Principais recursos:**

- Login e autenticação com JWT
- Controle de acesso por perfil
- Criação e gerenciamento de chamados
- Front-end em React
- API REST com Node.js
- PostgreSQL + Prisma

---

### 📦 Central de Pedidos

API desenvolvida para gerenciamento e processamento de pedidos de diferentes empresas.

**Principais recursos:**

- API REST
- Autenticação JWT
- Validação com Zod
- Paginação e filtros
- Gerenciamento de pedidos e itens
- Controle de status
- PostgreSQL + Prisma
- Docker
